StackCado Data public · MIT-licensed merge

This repository hosts the public, version-controlled data files used by the StackCado Chrome extension, maintained by HighTicketDeals.com.

Files

  • signatures.json — Detection signatures (auto-merged weekly from Wappalyzer's open-source database, MIT licensed, plus custom StackCado entries).
  • pricing.json — Verified pricing tiers per tool, with last_verified date and source_url so users can independently confirm.
  • reviews.json — Mapping of detected tools to in-depth, human-written reviews on HighTicketDeals.com.
  • privacy.html — The official Privacy Policy for the StackCado Chrome extension.

How updates work

Signatures are auto-synced every Monday by a GitHub Action. Prices are verified manually (transparent commit history) and a weekly Issue lists any entry older than 30 days.

License

Data files are released under the MIT license. Wappalyzer signatures retain their original MIT license from enthec/webappanalyzer.
